The 60-day study plan

Start with Linux and networking. Build up to operating AWS infrastructure, deploying safely, and working through incidents under pressure.

Open the day-by-day plan →
  1. Days 1–7

    Linux and troubleshooting

    DNS, TCP, TLS, HTTP, Linux, Git, Bash, and Python

  2. Days 8–14

    AWS architecture

    IAM, multi-account design, VPCs, hybrid networks, and service choices

  3. Days 15–21

    Terraform

    Modules, remote state, locking, imports, drift, and plan reviews

  4. Days 22–28

    Ansible and integration

    Repeatable playbooks, rolling patches, ESB, and message delivery

  5. Days 29–35

    CI/CD and release management

    Follow a commit through Docker, Jenkins, GitHub Actions, and a production rollout

  6. Days 36–42

    Kubernetes, EKS, and Argo CD

    Scheduling, traffic, cluster operations, and GitOps

  7. Days 43–49

    Observability, SRE, and data

    Telemetry, SLOs, incidents, databases, and recovery

  8. Days 50–56

    Platform engineering and cost

    Security, self-service design, FinOps, and senior ownership

  9. Days 57–60

    Mock interviews

    Architecture, incident response, live coding, and a targeted retest
